ML-DSA-87 signature verification

Checks a post-quantum signature (FIPS 204, ML-DSA-87) entirely in this browser with QoreChain's official @qorechain/pqc package. There is no server-side check, no QoreChain RPC call, and no other network request.

  • Asks only for a public key, a message, and a signature.
  • Never asks for a secret key, seed, or recovery phrase.
  • Never signs anything and never sends a transaction.

Inputs hexadecimal, no 0x prefix
